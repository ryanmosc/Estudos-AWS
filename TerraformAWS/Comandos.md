# Principais comandos
```
terraform init - Inicia o projeto (Baixa providers e prepara o diretório).
```

```
terraform fmt - Formata o código 
```

```
terraform validate - Verifica se a configuração está valída.
```

```
terraform plan - Mostra o que será feito 
```

```
terraform apply - Aplica / inicia o fluxo
```

```
terraform destroy - Destroi o que foi criado 
```
