# EC2 (Elastic Compute Cloud)

**O QUE É?**
A EC2 é um computador virtual (VPS) que fornece um serviço de computação em nuvem. Este serviço possui tudo que um computador possui, como: CPU, Memoria RAM, Disco, SO, placa de rede, Endereço ip e etc...
A EC2 é um serviço elastico, ou seja, pode aumentar ou diminuir recursos conforme a necessidade.

**QUANDO UTILIZAR UMA EC2?**
Sempre que você precisar hospedar APIS, SITES, BANCO DE DADOS (De forma que você queira ter 100% de controle), VPN, Servidor de arquivos proprio, Jenkins, GitLab e etc...
