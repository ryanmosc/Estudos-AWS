# EBS (EC2

É um dispositivo de armazenamento (É o HD / SSD) de uma instancia.
- Sempre que um volume EBS for criado ele é replicado em outra zona de disponibilidade (Um Backup).
- O volume EBS é fora da instancia.
- Você paga pelo armazenamento (Mesmo com a instancia desligada, afinal o ebs é a parte)
