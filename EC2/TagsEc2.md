# TAGS (EC2


São rotulos de marcação / identificação de recurso da aws. Elas funcionam como chave e valor.

{
"owner": "ryan"
}

**Observações gerais:**
- São case sensitive (**CUIDADO**)
Onde são usadas:
- Organização 
- Controle de acesso
- Automação
- Alocação de custos
- Governança
  
**OBSERVACOES:**
- Cada recurso pode ter no máximo 50 tags
- Não podemos usar o prefixo " aws: "
- cada chave é exclusiva e não pode ser repetida em um recurso
