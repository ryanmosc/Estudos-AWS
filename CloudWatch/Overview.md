# AWS CLOUD WATCH

Serviço responsavel por monitorar e gerar metricas sobre seus recursos utilizados na aws.
É um serviço mais do que pago.

**TPOS:**

- Básico: Realizado a cada 5mnts 
- Detalhado: Realizado a cada mnt

**COMPONENTES:**

- Dashboards
- Alarmes
- Eventos
- Metricas
- Logs (Centralização)

**CloudWatch Agent**
- É um software desenvolvido para coletar métricas detalhadas de sistemas operacionais.
- Para utilizar precisa de um IAM user e uma role.
